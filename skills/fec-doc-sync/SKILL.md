# Frontend documentation synchronization

Follow the [common documentation method](references/common/doc-sync.md) for evidence, multilingual consistency and delivery records.

## Frontend facts

Inspect package.json, lockfiles, framework/build configuration, env examples, routes, API clients/server routes, types/schemas, components, tests, CI and deployment files.

## Frontend synchronization scope

Check root, package, application, deployment and runtime READMEs, docs, ADRs, changelogs, environment and setup guides. Compare routing/API behavior, client integration, support matrices, plugin entry points, commands, report paths, metadata and example prompts.

Check public facts in every existing language. Record sources, changed/unchanged documents and translation review needs using the common method. Use the project's existing content, type, test and packaging checks.
