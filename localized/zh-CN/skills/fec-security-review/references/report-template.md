# 安全审查报告模板

```markdown
# 安全审查报告

> 生成时间: YYYY-MM-DD HH:mm
> 评审工具: frontend-craft

> 审核模式：改动审核 / 指定范围审核 / 全项目审核
> 目标范围：路径或 PR/提交
> 已审核：文件或模块清单
> 排除项：路径及原因
> 未覆盖：剩余文件或模块清单（无则注明）
> 完成状态：完成 / 部分完成
> 验证结果：命令、结果及未执行原因

## CRITICAL / 高危 (N项)
- **[文件:行号]** 风险描述 -> 修复建议

## HIGH / 中高危 (N项)
- ...

## MEDIUM / 中危 (N项)
- ...

## LOW / 低危或建议 (N项)
- ...

## 已通过的安全检查
- ...

**整体安全等级**: 安全 / 存在风险 / 高危需修复
```

审查完成后，将报告保存到 `reports/security-review-YYYY-MM-DD-HHmmss.md`，并告知用户报告路径。

改动审核保留合并建议；指定范围和全项目审核输出风险评估。部分完成时，结论仅适用于已审核范围，不构成全项目通过结论。
