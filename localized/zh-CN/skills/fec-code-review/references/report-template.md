# 代码审查报告模板

```markdown
# 代码审查报告

> 生成时间: YYYY-MM-DD HH:mm
> 评审工具: frontend-craft

> 审核模式：改动审核 / 指定范围审核 / 全项目审核
> 目标范围：路径或 PR/提交
> 已审核：文件或模块清单
> 排除项：路径及原因
> 未覆盖：剩余文件或模块清单（无则注明）
> 完成状态：完成 / 部分完成
> 验证结果：命令、结果及未执行原因

## CRITICAL / 必须修改 (N项)
- **[文件:行号]** 问题描述 -> 建议修改

## HIGH / 建议优化 (N项)
- ...

## MEDIUM / 可选优化项 (N项)
- ...

## LOW / 观察项 (N项)
- ...

## 做得好的地方
- ...

## 风险等级：低 / 中 / 高

**总体评价**: 改动审核填写合并建议；指定范围或全项目审核填写低 / 中 / 高风险及阻塞问题
```

评审完成后，将报告保存到 `reports/code-review-YYYY-MM-DD-HHmmss.md`，并告知用户报告路径。

改动审核保留合并建议；指定范围和全项目审核输出风险评估。部分完成时，结论仅适用于已审核范围，不构成全项目通过结论。
