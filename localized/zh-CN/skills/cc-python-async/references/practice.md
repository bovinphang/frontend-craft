# Python 异步生命周期

## 关键检查

1. 映射事件循环工作、阻塞客户端、任务归属及资源获取；选择任务组 API 前确认解释器/运行时特性。

2. 不可避免阻塞操作放入有界执行器，或使用既有异步客户端；同时限制等待和活跃工作。

3. 取消等待协程不一定停止底层线程或 I/O，资源归属仍跟随实际操作。

4. 使用适当异步清理/finally 并保留取消语义，底层操作仍使用资源时不要提前释放池名额。

5. 定义停止接单、排空/取消及完成期限，将任务错误交给拥有方，避免后台异常丢失。

6. 测试获取资源前后取消、驱动超时、池饱和与停机；驱动不可中断属于需明确报告的限制。

## 边界与案例

适用场景：
- 隔离 async Python handler 中的阻塞客户端
- 在 asyncio 取消后正确归还池资源
- 限制 Python 线程卸载及任务并发
- 测试 Python 异步停机与超时收尾

应用角色按实际证据区分；本语言模块可用于库、CLI、桌面或服务，框架问题另选专项。

## 交付要求

- 已读取的工程/契约证据及变更作用域。
- 选用方案、关键不变量、资源/错误或失败边界。
- 实际运行的命令与结果，未运行项及不能证明的结论。
- 兼容、恢复/回滚或后续处理限制；评审结论须给可核实位置。
